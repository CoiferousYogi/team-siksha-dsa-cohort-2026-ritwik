# DSA Cohort 2026

## 📂 Repository Structure

**sessions/** contains one folder per session named `YYYY-MM-DD-sessionX`

**Each session folder contains:**
- `YYYY-MM-DD-sessionX.md`
    - Relevant resources for that session, including:
      - 🔗 Problem links
      - 📝 Quizzes
      - 📚 Assignments
      - 🎨 Excalidraw diagrams (for visual explanations and walkthroughs)
      - 📄 Any additional supporting files or notes
      
- `solutions/` folder with subfolders:
  - `cpp/` - C++ solutions
  - `java/` - Java solutions  
  - `python/` - Python solutions
  - `js/` - JavaScript solutions

**Example path:** `sessions/2026-02-17-session31/solutions/python/`

## 🌟 Contribute Solutions!

**Everyone is invited to contribute!** Add your solutions via Pull Requests.

### 📝 Solution File Naming Convention
problem_name_your_name.extension

**Examples:**
- search_in_sorted_rotate_array_ii_Garima.java
- longest_substring_without_repeating_characters_Anjali.py

**Steps to contribute:**
1. Find a session: `sessions/2026-02-17-session31/`
2. Pick your language folder: `solutions/java/`
3. Create file: `problem_name_your_name.java`
4. Solve problems from the session `.md` file
5. Submit PR! 🎉
