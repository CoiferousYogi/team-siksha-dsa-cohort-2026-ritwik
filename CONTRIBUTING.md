# 🌟 Contribute Solutions!

**Everyone is invited to contribute!** Add your solutions via Pull Requests.

### 📝 Solution File Naming Convention
problem_name_your_name.extension

**Examples:**
- search_in_sorted_rotate_array_ii_Garima.java
- longest_substring_without_repeating_characters_Anjali.py

**Steps to contribute:**
1. Find a session: `sessions/2026-02-17-session31/`
2. Pick your language folder: `solutions/java/`
3. Create file: `problem_name_your_name.java`
4. Solve problems from the session `.md` file
5. Submit PR! 🎉
